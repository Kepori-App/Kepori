Kepori 是面向 iPhone 和 iPad 的本地优先收藏与阅读工具。把散落各处的公开链接保存下来，用空间、笔记和高亮整理，在需要时通过关键词或本地智能搜索找回。

Kepori is a local-first collection and reading app for iPhone and iPad. Save public links, organize them with spaces, notes and highlights, and find them again with keyword or on-device intelligent search.

## 收藏之后，慢慢看

- **保存与阅读**：尝试提取公开链接中的文字与可保存媒体，保留作品来源。解析结果取决于来源页面和访问条件。
- **整理与记录**：用空间组织内容，为阅读添加笔记和高亮。
- **本地搜索**：关键词搜索与设备上的智能检索，搜索不依赖云端 AI。
- **内容在本机**：无需 Kepori 账号；来源加载、媒体获取和 Apple 内购仍可能联网。
- **导出与分享**：按作品支持的格式导出 Markdown、HTML 或 PDF。
- **适配你的设备**：支持 iOS 17 / iPadOS 17 及以上版本。
